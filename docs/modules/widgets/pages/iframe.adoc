==== Widget Iframe (intégration d’application externe)

Permet l’utilisation d’application externe, qui autorise sa connexion,
via une url. L’application sera disponible dans un contexte de
navigation imbriqué. Exemple de manifest :

[source,js]
----
{
    type: 'iframe',
    layout: {
        x: 1,
        y: 1,
        height: 12,
        width: 12
    },
    options: {
        src: 'https://www.google.fr/maps?hl=fr'
    }
}
----
