== Widget Template (Template Angular)

Le templating utilisé ressemble à celui de Angular mais est très
simplifié et permet seulement un nombre limité d’actions/pipes.

Exemple de manifest :

[source,js]
----
{
    type: 'template',
    layout: { x: 1, y: 1, height: 12, width: 12 },
    options: {
      html:
        '<h1> Template </h1>' +
        "<h2>Année de naissance: {{rs['8c2833a9-668d-49d0-a7e9-e67b4d7afa06'][0].attributes.an_nais }}</h2>" +
        "<p>Choc: {{rs['411a19f5-9d00-4028-b4b6-4b04101f6316'][0].attributes.choc[0]}}</p>"
    },
    datasource: '39061554-298f-4f56-8cd2-51ccec998307'
}
----
