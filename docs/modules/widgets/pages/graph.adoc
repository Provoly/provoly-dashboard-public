==== Widget Graph (graphe de relations)

Permet de visualiser les relations entre les données. Le paramétrage du
widget mets à disposition 3 algorithme de disposition different :
-dagreCluster -d3ForceDirected -ellipsoid

Ainsi que l’utilisation d’une propriété de regroupement(id,type, etc… ).

Exemple de manifest :

[source,js]
----
{
    type: 'graph',
    layout: {
    x: 1,
    y: 1,
    height: 12,
    width: 12
    },
    options: {},
    datasource: '39061554-298f-4f56-8cd2-51ccec998307'
}
----
