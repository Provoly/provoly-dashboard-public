== Widget Tile (Tuiles)

Permet la restitution des données et de leurs détails dans des tuiles.
Le paramétrage permet de filtrer l’affichage des données.

Exemple de manifest :

[source,js]
----
{
    type: 'tile',
    layout: {
        x: 1,
        y: 1,
        height: 12,
        width: 12
    },
    options: {},
    datasource: '39061554-298f-4f56-8cd2-51ccec998307'
}
----
