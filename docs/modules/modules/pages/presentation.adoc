=== Presentation

Le module presentation permet :

- l’affichage de l’ensemble des
tableaux de bord disponibles,
- la consultation, la modification et le partage
(public, privé ou par groupe) d'un tableau de bord.

Il y a également la possibilité de créer un tableau de bord via un bouton
`+créer un tableau de bord+` qui permet d’accéder au formulaire de
création.
