=== Personnaliser les grilles

Pour les cas particuliers, il est possible de créer ses propres grilles de dépose de placement automatique des restitutions dans un dashboard.
Cela se fait en fournissant un manifest de gabarit

Voici un exemple, avec le type '2/1' pour le type de grille:
----
PryDashboardModule.forRoot(
      {
        ...,
      [
        {
          type: '2/1',
          label: '@pry.toolbox.layout.2/1',
          description: '@pry.toolbox.layout.2/1_detailled',
          rows: 2,
          columns: 2,
          places: [
            { x: 1, y: 1, width: 1, height: 1 },
            { x: 1, y: 2, width: 1, height: 1 },
            { x: 2, y: 1, width: 1, height: 2 }
          ]
        }
      ]
    ),
----

Dans cet exemple les libellés pour cette nouvelle grille utilisable par les utilisateurs sont ajoutés
de cette manière mais on pourrait aussi les mettre directement et ne pas les internationaliser :
----
this.translateService.addLangObject('fr', 'custom-grid', {
      '@pry': {
        toolbox: {
          layout: {
            '2/1': '2 à gauche, 1 à droite',
            '2/1_detailled':
              'Affichage de 2 restitutions sur la partie gauche, et un sur la partie droite. Le placement est guidé par le système.'
          }
        }
      }
    });
----

Un rendu de l'affichage sur un dashboard miniature sera proposé en représentation pour le choix du gabarit.
